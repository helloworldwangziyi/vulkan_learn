# VulkanLearn：从零手写 Vulkan 渲染器

这是一份**从零开始、逐课递进、每课一个可执行文件**的 Vulkan 中文教程。跟着写完第 11 课，你就能在屏幕上画出自己的第一个三角形；全部 22 课结束时，你会拥有一个带贴图、深度测试、Mipmap 和 MSAA 的维京小屋渲染器。

教程的每一章都对应仓库 `lessons/` 下的一个源码文件，**章节讲解与代码逐段对应**——代码里几乎每行都有中文注释，两者互为参照。

## 这份教程有什么不同

- **全程显式，不藏黑盒**：Vulkan 以"啰嗦"著称，但这份啰嗦正是学习图形 API 的最佳教材——画布哪来、开工前清不清、画完留不留，每一句都要你亲口告诉驱动
- **踩坑优先**：每章末尾的"踩坑记录"不是附录，而是正文的延伸——它们来自真实编译/运行错误和校验层报文，是最有价值的部分
- **逐课可运行**：不是"最终项目 + 回溯讲解"，而是每一课都是独立的 `NN_xxx.cpp`，编译即跑，改哪课坏不了其他课

## 学习路线总览

| 阶段 | 课程 | 你在做什么 |
|---|---|---|
| 地基 | 第 1-5 课 | 连接驱动、装上报错、选中显卡、租下设备、把渲染目标挂到窗口 |
| 画布 | 第 6-9 课 | 交换链拿到"纸"、图像视图定"读法"、图形管线造"笔"、帧缓冲成"成品画布" |
| 动笔 | 第 10-11 课 | 命令缓冲写下"作画指令"，同步对象管"流水线节拍"，三角形上屏 |
| 进阶 | 第 12-22 课 | 顶点/索引/Uniform 数据上显存，贴图、深度、模型、Mipmap、MSAA |

完成入门 22 课后，仓库还提供 `advanced/` 目录的进阶实战（交换链重建、push constants、描述符进阶、离屏渲染……）与配套的《Vulkan 中高级学习路线》，见侧边栏附录。

## 怎么用这份教程

1. 先读[环境与构建](setup.md)，把开发环境跑通
2. 按章节顺序阅读，**每章的"动手改"环节一定要自己做**——尤其第 11 课的三角形练习
3. 卡住时看对应源码 `lessons/NN_xxx.cpp` 的注释，再回头看本章讲解
4. 遇到报错先查[踩坑记录总表](pitfalls.md)
