# 第 4 课 · 逻辑设备与队列

> 对应源码：`lessons/04_logical_device.cpp`
> 目标：基于选中的物理设备创建 `VkDevice`——全教程第一次真正"创建" GPU 侧对象，并取出命令的入口：队列。

## 4.1 物理设备 vs 逻辑设备：楼与钥匙

第 3 课的 `VkPhysicalDevice` 只是"指着楼说就是那栋"。逻辑设备才是你向驱动申请的**使用许可**：

| | 物理设备 | 逻辑设备 |
|---|---|---|
| 怎么得到 | 枚举系统资源 | `vkCreateDevice` 创建 |
| 类比 | 整栋楼的产权 | 你租下的那几间房的钥匙 |
| 能干什么 | 只读查询（能力、限制） | 创建缓冲、提交命令……真正干活 |

从物理设备查属性（`vkGetPhysicalDeviceProperties` 之类）不经过逻辑设备；而从这一刻起，**几乎所有干活的对象都从逻辑设备创建**。

## 4.2 创建逻辑设备：一份"租房申请"

```cpp
VkDeviceQueueCreateInfo queueCreateInfo{};
queueCreateInfo.sType = VK_STRUCTURE_TYPE_DEVICE_QUEUE_CREATE_INFO;
queueCreateInfo.queueFamilyIndex = indices.graphicsFamily.value();
queueCreateInfo.queueCount = 1;
float queuePriority = 1.0f;              // 0.0~1.0，相对优先级
queueCreateInfo.pQueuePriorities = &queuePriority;

VkDeviceCreateInfo createInfo{};
createInfo.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO;
createInfo.pQueueInfo = &queueCreateInfo;      // 要租哪些队列（本课：图形族 1 个）
createInfo.pEnabledFeatures = nullptr;         // 本课不申请额外特性

if (enableValidationLayers) {                   // 第 2 课的层，设备级要再声明一次！
    createInfo.enabledLayerCount = ...;
    createInfo.ppEnabledLayerNames = ...;
}

vkCreateDevice(physicalDevice, &createInfo, nullptr, &device);
```

三个要点：

1. **队列要在申请时声明**：要哪个族、几个队列、优先级多少。之后不能再加——想换只能重建设备
2. **校验层是"两道关"**：实例级声明过一次，设备级还要再声明。漏了这层，设备创建期的错误没人报
3. `queuePriority` 只在**同族多个队列之间**有区分意义，单个队列填 1.0 即可

## 4.3 取出队列句柄

设备建好了，队列作为它的"配套产物"取出来：

```cpp
vkGetDeviceQueue(device, indices.graphicsFamily.value(), 0, &graphicsQueue);
//                                                      ^ 族内序号（第 0 个）
```

注意队列**不是**你创建的——它只是设备内部资源的句柄，随设备生灭，不需要销毁。

这个 `graphicsQueue` 暂时存着，第 10 课的命令缓冲、第 11 课的呈现，都要通过它提交。

## 4.4 设备特性：先不申请，但要知道它存在

`pEnabledFeatures = nullptr` 表示"不用任何可选特性"。但要知道：**很多能力不是默认开启的**，比如各向异性采样、深度钳制、逻辑运算——用之前必须在这里声明启用。本课全不用，所以空着；等到需要的那天（纹理采样器那一课），会回来填它。

## 踩坑记录

- **两道关的校验层**：实例层 ≠ 设备层，创建 `VkDevice` 时漏声明层，是这个阶段最常见的静默失败源
- **`VkDeviceQueueCreateInfo` 的优先级数组**：`pQueuePriorities` 指向的数组长度必须 ≥ `queueCount`，指向局部变量没问题（创建时会拷贝），但数组本身要匹配数量

## 小结

> 物理设备是楼、逻辑设备是钥匙：租房申请里写清要哪些队列（族 + 数量 + 优先级），校验层要过两道关，队列用 `vkGetDeviceQueue` 随取随用。手里有了钥匙，下一课把钥匙插进锁孔——让渲染结果能落在窗口上。
