# 第 7 课 · 图像视图

> 对应源码：`lessons/07_image_views.cpp`
> 目标：给交换链的每张图创建 `VkImageView`——最短的一课，但概念很重要。

## 7.1 VkImage 只是"一块像素内存"

上一课拿到的 `VkImage`，本质上只是**一段格式已知的显存**。它自己不带任何"怎么读"的信息：

- 像素是什么排布？（格式）
- 取色的通道顺序？（RGBA 还是 BGRA）
- 看作 2D 图还是 Cube 的某个面？

直接拿原始内存进管线是不行的，需要一层"解读器"——这就是图像视图：

```
VkImage  ──►  VkImageView  ──►  管线/着色器
"像素堆"      "解读说明书"        按说明书取色
```

类比：同一份数据文件，VS Code 按文本打开、Excel 按表格打开、播放器按视频解码——数据一样，"视图"不同。

## 7.2 视图说明书里都写什么

```cpp
VkImageViewCreateInfo viewInfo{};
viewInfo.image = swapChainImages[i];
viewInfo.viewType = VK_IMAGE_VIEW_TYPE_2D;        // 当作 2D 图看（还能是 3D/Cube）
viewInfo.format = swapChainImageFormat;            // 解读格式（和图保持一致）

viewInfo.components.r = VK_COMPONENT_SWIZZLE_IDENTITY;   // 通道映射：原样
viewInfo.components.g = VK_COMPONENT_SWIZZLE_IDENTITY;
viewInfo.components.b = VK_COMPONENT_SWIZZLE_IDENTITY;
viewInfo.components.a = VK_COMPONENT_SWIZZLE_IDENTITY;

viewInfo.subresourceRange.aspectMask = VK_IMAGE_ASPECT_COLOR_BIT;  // 看作颜色数据
viewInfo.subresourceRange.baseMipLevel = 0;
viewInfo.subresourceRange.levelCount = 1;          // 只用 mip 0（交换链图没有 mip 链）
viewInfo.subresourceRange.baseArrayLayer = 0;
viewInfo.subresourceRange.layerCount = 1;          // 单层（非数组图）
```

几个字段的直觉：

- **components（通道映射）**：允许你说"把文件的 B 当 R 读"。`IDENTITY` 是"如实解读"。什么时候用得上？读某些 BGRA 排布的老格式图时，可以不转数据只转解释——零成本换序
- **subresourceRange（子资源范围）**：一张图里可能有多层（数组）、多级（mip 链）、多个用途（颜色/深度/模板），视图要声明"我取哪部分、当什么用"。本课只取"第 0 层第 0 级、当颜色"——后面深度缓冲、mipmap 会回来扩展这里

## 7.3 一张图配一个视图

```cpp
swapChainImageViews.resize(swapChainImages.size());
for (size_t i = 0; i < swapChainImages.size(); i++) {
    swapChainImageViews[i] = createImageView(swapChainImages[i], ...);
}
```

交换链给几张图就建几个视图。注意生命周期绑定：**视图引用的图死了，视图必须先死**——销毁顺序上视图在交换链之前。

## 7.4 为什么不干脆让 VkImage 自带这些信息？

Vulkan 的哲学："最常用组合要最高效，就要把灵活性拆开卖。"

同一张图可能同时需要多种解读（比如做通用计算的图，既要采样又要存储）。数据只有一份，视图可以有多份——分离设计让"一份数据、多种看法"零成本。这也是 Vulkan 和 OpenGL 的鲜明对比：GL 里 texture object 把这些全揉在一起，方便但失去了组合自由。

## 踩坑记录

- **`levelCount`/`layerCount` 写 0**：这是"视图为空"的报错来源之一。交换链图没有 mip 链，但字段要写明"1 级 1 层"而不是 0
- **格式必须兼容**：视图格式与图格式通常必须相同（或在同一兼容性列表内），随手填错会在创建时被校验层拦下

## 小结

> VkImage 是像素堆、VkImageView 是解读说明书；通道映射和子资源范围是说明书的两项核心条款；一张图可配多个视图。纸和读法都齐了，下一课造"笔"——图形管线，全教程最厚的一课。
