# 第 3 课 · 物理设备与队列族

> 对应源码：`lessons/03_physical_device.cpp`
> 目标：从系统里挑出一块能用的显卡，并理解"队列族"这个 Vulkan 的核心概念。

## 3.1 VkPhysicalDevice 是"句柄"，不是对象

Vulkan 里的对象分两类：

- **你创建的**（实例、设备、缓冲……）：`vkCreateXXX` 得到，`vkDestroyXXX` 归还
- **系统里本来就有的**（物理设备）：**枚举**得到，你只"指向"它，永远不销毁

```cpp
uint32_t deviceCount = 0;
vkEnumeratePhysicalDevices(instance, &deviceCount, nullptr);   // ① 问数量
std::vector<VkPhysicalDevice> devices(deviceCount);
vkEnumeratePhysicalDevices(instance, &deviceCount, devices.data());  // ② 取数据
```

老朋友"两段式枚举"又来了（第 1 课刚学过）。遍历每块卡，第一块"合适"的就选中——本教程的简化策略是"能跑就行"，第 5、6 课会不断给 `isDeviceSuitable` 加码。

## 3.2 队列族：显卡里的"专科门诊"

GPU 内部不是一条流水线，而是**按功能编组的多条队列**。一组同类的队列就是一个**队列族**（Queue Family）：

```
一块显卡
├── 族 0：图形（graphics）—— 跑渲染命令
├── 族 1：计算（compute）—— 跑通用计算
├── 族 2：传输（transfer）—— 专做数据搬运
└── 族 3：稀疏绑定（sparse binding）……
```

每个族有自己的**专长**。渲染要求队列族支持 `VK_QUEUE_GRAPHICS_BIT`。

查询也是两段式——这回是查"族清单"：

```cpp
uint32_t queueFamilyCount = 0;
vkGetPhysicalDeviceQueueFamilyProperties(device, &queueFamilyCount, nullptr);
std::vector<VkQueueFamilyProperties> queueFamilies(queueFamilyCount);
vkGetPhysicalDeviceQueueFamilyProperties(device, &queueFamilyCount, queueFamilies.data());

for (const auto& queueFamily : queueFamilies) {
    if (queueFamily.queueFlags & VK_QUEUE_GRAPHICS_BIT) {
        indices.graphicsFamily = i;   // 记下族下标
    }
}
```

## 3.3 第一次见 `std::optional`：有/无 比 数值 更重要

本课的 C++ 小技巧值得记住。队列族的下标可能找到、也可能找不到，"没找到"不能拿 `-1` 或 `0` 冒充：

```cpp
struct QueueFamilyIndices {
    std::optional<uint32_t> graphicsFamily;
};

bool isComplete() { return graphicsFamily.has_value(); }
```

`std::optional` 把"值是否存在"变成类型系统的一部分——第 5 课它会升级成"双 optional"（还要找呈现族）。这是 C++17 最值得掌握的特性之一，之后的选择设备判断全靠它。

## 3.4 本课的选择标准

```cpp
bool isDeviceSuitable(VkPhysicalDevice device) {
    QueueFamilyIndices indices = findQueueFamilies(device);
    return indices.isComplete();   // 本课：只要有图形族就算合格
}
```

别嫌简陋——"选卡标准"是渐进式设计的：第 5 课加"呈现族"，第 6 课加"交换链扩展"。现在先跑通流程。

## 踩坑记录

- **独显/核显/软渲染都在候选里**：枚举结果可能包含 CPU 软渲染器（llvmpipe），选卡标准就是为了筛掉它们
- **队列族的专长是位标志**：一个族可以同时支持图形+计算+传输（现代卡常见），判断用 `&` 而不是 `==`

## 小结

> 物理设备是系统资源、枚举而得；队列族是 GPU 的功能编组，渲染要找图形族；"是否存在"用 `std::optional` 表达。显卡选好了，但它还只是一块"看得见摸不着"的硬件——下一课去"租"下它的使用权。
